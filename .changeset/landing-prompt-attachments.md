Visitors can attach up to five PDF or Word documents to the landing-page prompt,
with the paperclip button or by dropping them on the prompt. The files upload
while the visitor types and are added to the project created at signup, where
their text is extracted for the assistant; the first chat message names them.

Only files that are really in storage are named in the first message.
