The project sign-up modal opens as soon as a visitor submits their prompt and asks only for an email.

- **Opens at once:** the modal no longer waits 4–7 seconds for the generated project name. The name fills in when it arrives.
- **Email only:** visitors see a summary of their project, the email field and one button. Project name and prompt editing sit behind "Edit details", which opens on its own if the prompt check needs more.
