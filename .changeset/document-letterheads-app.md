Chat documents get real letterheads. The document preview shows the office logo
and styles the letterhead like the PDF export. Offices and organizations can
configure a letterhead (agency columns, logo left, centered or a full-width
banner image, with an optional brand color), keep a library of extra
letterheads, and import one from an existing PDF or image. Each document can
pick its letterhead from the panel header. When a letterhead is configured the
AI no longer writes a letterhead table, and the office's document details
(signatory, contacts, office hours, file code, other facts) fill the document
instead of `[INSERT]` placeholders. A new "Fill placeholders" panel lists the
remaining placeholders and fills each one across the whole document, optionally
remembering the value for the office.
