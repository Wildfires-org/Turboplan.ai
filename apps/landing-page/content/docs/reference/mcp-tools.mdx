The TurboPlan MCP server exposes **60 tools** to connected agents. Tool names
follow a `verb_noun` convention (`list_projects`, `create_task`,
`update_task_status`), so they read the way you'd describe the action out loud.

If you haven't connected a client yet, start with the
[MCP server](/docs/reference/mcp-server) page — it covers creating a Personal
Access Token and pointing your client at the server.

## Input schemas

This page lists the tools, not their parameters. The server advertises the full
input schema for every tool over the protocol itself, so the most accurate
reference is your client: connect, then ask it to list the tools and their
arguments. The schemas you see there always match the deployed server.

## How reads and writes are metered

Each tool is classified as a **read** or a **write** purely from its name. A tool
counts as a write when its name starts with `create_`, `update_`, `delete_`,
`upload_`, `add_`, `move_`, or `remove_`; everything else is a read. That
classification decides which rate limit applies — write tools get 30
requests/min per user, read tools get 60. See
[Rate limits](/docs/reference/mcp-server#rate-limits) for the full picture.
