You don't need to install anything to get started with TurboPlan. Here is the
short list of what you need.

## What you need

- **A TurboPlan account.** You sign in through the main TurboPlan app. If you
  don't have an account yet, you can create one from the <a href={routing.signIn()}>sign-in page</a>.
- **A modern web browser.** TurboPlan runs entirely in the browser — no
  desktop install required.

That's it. Once you can sign in, you're ready to create your first project.
