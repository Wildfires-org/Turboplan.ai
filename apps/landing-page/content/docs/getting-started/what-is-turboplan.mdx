title: What is TurboPlan?
description: An AI environmental planning application where you run projects — from chat-driven setup to tasks, documents, and signatures.
---

TurboPlan is an AI environmental planning application. Once you sign in, your
work is organized into **projects**, and each project brings chat, tasks, maps,
documents, signing, and more together in one place. You set a project up by
talking to an AI chat, then manage the details from the project's sidebar.

## How your work is organized

TurboPlan uses a three-level hierarchy:

- **Organization** — the top-level container (for example, a government agency).
- **Office** — a division within an organization.
- **Project** — the unit of actual work, living inside an office.

Membership and roles apply at each level. Members can be an **Owner**,
**Editor**, or **Viewer**, and roles inherit downward through the hierarchy.

Every user also gets an automatically created **personal workspace** — your own
organization and office. New projects are always created there first, never
directly inside a government organization. You switch between organizations and
offices using the switcher in the sidebar.

## Inside a project

When you open a project, the sidebar shows a fixed set of feature modules. Each
one is a real, working part of the project:

- **Overview** — the project's landing view.
- **Chat** — the primary AI interface for setting up and working on the project.
- **Map** — upload and view GeoJSON or a zipped shapefile as boundary layers on
  an interactive map.
- **Tasks** — manage tasks and milestones in table, card, or Gantt-chart views,
  with AI-assisted creation.
- **Timeline** — a read-only activity log of changes across the project.
- **Comments** — a project-scoped discussion thread.
- **Documents** — upload, preview, and manage PDF and Word documents.
- **Signing** — request and complete document signatures.
- **Context** — add short labeled notes and links that get fed into the AI's
  system prompt as background for the project.
- **Members** — manage who has access to the project and their role.

## Where projects go from here

A project is created as a draft in your personal workspace. When it's ready, it
can be submitted to a government organization for review — separate from where
it was originally created.
