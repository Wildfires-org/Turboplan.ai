The **Fields** module lets you attach simple custom fields to a project — a way
to record structured details that don't belong in chat, tasks, or documents.

## Adding and managing fields

A field is a **label and a value**. From the Fields view you add a field by
giving it a label and its value, and it's then displayed on the project. You can
edit a field's value later or remove it entirely, and the add and edit dialogs
validate your input as you go.

Fields show up alongside the project's other details, giving anyone with access
a quick, consistent read of the facts you've recorded.
