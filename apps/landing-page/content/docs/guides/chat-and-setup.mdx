title: Chat and project setup
description: The chat-first setup flow, what the research agent can propose, and how project context shapes the AI.
---

Chat is the primary interface for setting up and working on a project. When you
create a project, you land directly in its **Chat** view — that's where setup
begins.

## Setting up through chat

You describe your project in the chat, and the AI helps you get it going.
Rather than filling in forms up front, you work conversationally and let the
chat drive the initial structure of the project.

## What the research agent can propose

An optional research agent can propose a starting point for the project — a set
of suggested **documents, milestones, tasks, and fields**. These are proposals,
not automatic changes: you review what the agent suggests and save the pieces
you want, adjusting or discarding the rest. This gives you a running start
without giving up control over what actually lands in the project.

## Project context

The **Context** module lets you add short labeled notes and links as background
for the project. These entries are fed into the AI's system prompt, so anything
you record there informs how the chat and agent reason about your project. Use
it to capture facts, constraints, or reference links you want the AI to keep in
mind.

## Moving on from chat

Once the project is set up, use the other feature modules in the sidebar to
carry the work forward — tasks and milestones, the map, documents, and signing.
The chat remains available throughout the life of the project.
