The **Tasks** module is where you plan and track the work in a project. It
covers both tasks and milestones, and gives you several ways to look at them.

## Views

You can view a project's tasks and milestones in three ways:

- **Table** — a structured list, useful for scanning and editing details.
- **Card** — a card-based layout for a more visual overview.
- **Gantt chart** — a timeline view for seeing schedules and how work is
  sequenced.

Switch between views depending on whether you're editing details, getting an
overview, or planning timing.

## AI-assisted creation

You don't have to build every task by hand. Tasks and milestones support
AI-assisted creation, so you can have the AI help generate them — this pairs
naturally with the research agent's proposals during
[chat setup](/docs/guides/chat-and-setup), which can suggest an initial set of
milestones and tasks for you to review and save.
